# Konfigürasyon

Bu klasör yalnızca sürümlenebilir ve gizli bilgi içermeyen ayarlar içindir. Parola, token, Wi-Fi anahtarı veya özel anahtar commit edilmez.

Planlanan katmanlar:

- `default.toml`: Güvenli varsayılanlar
- `development.toml`: Simülasyon/geliştirme
- `vehicle.example.toml`: Araç üstü örnek
